# Defibrillator coverage in Brighton & Hove

Analysis of the geographic distribution of publicly registered Automated
External Defibrillators (AEDs) across Brighton & Hove, with population and
accessibility overlays.

Published outputs:

- [Headline analysis](https://adamdennett.github.io/defibrillator-analysis/brighton_analysis.html)
  — the main writeup.
- [MCLP allocation](https://adamdennett.github.io/defibrillator-analysis/brighton_mclp.html)
  — solving a Maximum Coverage Location Problem to suggest where additional
  AEDs would most expand coverage.
- [Interactive map](https://adamdennett.github.io/defibrillator-analysis/defibrillator_map.html)
  — every registered device, browsable.
